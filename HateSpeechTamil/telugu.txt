This project is a **Multimodal Hate Speech and Offensive Content Identification System** for Telugu memes (Telugu HASOC). 

Memes contain two components:
1. **Visual content** (the image itself).
2. **Textual content** (text printed on the image).

To identify if a meme is abusive or offensive, the project uses a multimodal approach:
*   **Text Processing**: It combines OCR-extracted text (detected Telugu text on the image) and BLIP-generated image descriptions (captions) to capture semantic text features.

### What Happened?

The error **`ConnectionResetError: [WinError 10054]`** means that **your internet connection to PyPI (the Python Package Index server) was unexpectedly cut off** or forcibly closed while downloading the packages. 

This usually happens when:
1. **Temporary network instability**: Your internet dropped out briefly.
2. **Large file downloads**: Some of these packages (like `paddlepaddle`, `torch`, and `transformers`) are very large (hundreds of megabytes). If the download takes too long or is unstable, the remote PyPI server terminates the connection.

---

### How to Fix It

You can try the following steps to install the packages successfully:

#### 1. Increase the Timeout Limit and Avoid Cache
Running `pip` with a higher timeout threshold and disabling cache forces pip to retry downloading package chunks when there is high latency.

```bash
pip install --default-timeout=1000 --no-cache-dir pandas scikit-learn pillow tqdm
```

### Planner Response

In machine learning, a **test dataset** (or validation dataset) is crucial for evaluating how well your model actually performs on **completely new, unseen data**. 

In your specific project, there are two types of "test datasets" with different purposes:

---

### 1. The Internal Test/Validation Split (160 Labeled Images)
During training in `train_model.py`, the 800 labeled images are split:
*   **640 images (80%)** are used to **train** the model (learning to detect abuse).
*   **160 images (20%)** are used to **test** the model.

**Its Use:**
*   **Overfitting Check**: If a model gets 100% accuracy on the training images but only 50% on these test images, it has "overfit" (memorized the training data). The test split tells you the model's true capability on new data.
*   **Performance Metrics**: It is used to calculate **Accuracy**, **Precision**, **Recall**, and **F1-Score**.

---

### 2. The Official Test Dataset (200 Unlabeled Images)
This is the `test_data_Telugu.csv` file that has no labels (only image IDs).

### Planner Response

To check if your model is predicting correctly, you will use two types of evaluations: **quantitative metrics** (overall scores) and **qualitative testing** (individual checks).

Here is how you can do it:

---

### 1. Overall Performance Metrics (Statistical Check)
When you run the training script, it will print validation metrics on the screen at the end of each epoch. These numbers tell you how correct the model is overall:

*   **Accuracy (e.g., `0.85`)**: Means the model classified **85%** of the test images correctly.
*   **F1-Score**: This is the most important score. It balances **Precision** (how clean the "Abusive" predictions are) and **Recall** (how many of the actual abusive memes were caught). An F1-score above **0.80** is generally considered good.

---

### 2. Manual Testing (Visual/Intuitive Check)
Once we build the prediction script or the Web App, you can test it interactively:
1.  **Select a meme** (either from your dataset or a new one from the internet).
2.  **Upload it** to the predictor.
3.  **Inspect the output**:
    *   Compare the model's prediction (**"Abusive"** or **"Non-Abusive"**) against your own human judgment.
    *   Look at the **Confidence Score** (e.g., *"Abusive with 92% confidence"*). If the model is wrong but has low confidence (like *51%*), it means it was unsure. If it's wrong with *98%* confidence, it indicates the model has a blind spot.

---

### 3. Error Analysis / Confusion Matrix (Diagnostic Check)
We can generate a **Confusion Matrix** (a $2 \times 2$ grid) at the end of training. It breaks down the exact count of predictions:

*   **True Negatives (TN)**: Clean memes correctly predicted as *Non-Abusive*.
*   **True Positives (TP)**: Offensive memes correctly predicted as *Abusive*.
*   **False Positives (FP)**: Clean memes that the model *incorrectly flagged* as Abusive.
*   **False Negatives (FN)**: Offensive memes that the model *missed* (classified as Non-Abusive).

*Analyzing the **False Negatives** and **False Positives** helps you understand exactly where the model is struggling (e.g. is it failing to detect sarcasm, or is it misinterpreting specific Telugu slang?).*
